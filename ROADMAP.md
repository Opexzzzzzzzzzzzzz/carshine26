# CarShine — интернет-магазин детейлинга. Снимок проекта

Замена старого сайта на Tilda на кастомный магазин. **ЗАПУЩЕН В ПРОДЕ: https://carshine26.ru** (SSL, свой домен). Это источник правды по проекту — обновлять здесь.

---

## Стек
- **Next.js 16** (App Router) + React 19 + TypeScript + **Tailwind v4**
- **Prisma 6 + SQLite** (файловая БД `prisma/dev.db`, идеально под 1 ГБ/2 ГБ VPS)
- Дизайн: тёмный премиум (графит + золото), шрифты **Unbounded** (дисплей) + **Manrope** (текст), кириллица
- Иконки категорий/преимуществ — **Google Material Symbols** (шрифт подключён в `layout.tsx`)

## Данные / каталог
- **1747 товаров** из Tilda-экспорта (`Товары CarShine26.xlsx`) → `data/catalog.json` → сидятся в SQLite (`prisma/seed.ts`, `npm run db:seed`).
- 38 категорий сгруппированы в **6 разделов меню** (`src/lib/groups.ts`).
- Описания: ~1580/1747 заполнены (брали более полное из колонок G/H, чистили HTML-теги/сущности).
- **Фото сейчас — с tildacdn** (внешние, `next.config.ts` → `images.remotePatterns`). Скачанная база на будущее: `data/images/` (1921 файл, 418 МБ, **в .gitignore**), карта в `data/images-manifest.json` / `image-map.csv`. Поля `localImage`/`localImages` в базе готовы для переключения на свой хостинг.

## Архитектура данных
- `src/lib/shop.ts` — **клиент-безопасный** слой: типы, группы, категории (`src/data/categories.json`), бренды (`src/data/brands.json`), `formatPrice`, `plural`.
- `src/lib/queries.ts` — **server-only** запросы к БД (Prisma).
- `src/lib/db.ts` — Prisma client (singleton). `src/lib/auth.ts` — вход в админку. `src/lib/settings.ts` — key/value настройки в БД.
- Корзина (`src/lib/cart.tsx`) хранит **снимок товара** в localStorage (клиенту не нужен весь каталог). **Избранное удалено** (по решению).

## Страницы (витрина)
- `/` главная (герой, слоган **«Ваш детейлинг начинается здесь. CarShine26»**, разделы, популярные, бренды)
- `/catalog` все товары; `/catalog/[group]` раздел с фильтрами (категория/бренд/цена/наличие), поиск в разделе, «показать ещё». Панель фильтров скроллится независимо. Список брендов сужается под выбранную категорию.
- `/product/[slug]` карточка (галерея, описание, похожие, JSON-LD)
- `/search?q=` глобальный поиск
- `/about`, `/contacts` (адрес — ссылка на Яндекс.Карты), `/privacy`
- Корзина 1:1 со старым сайтом: поля Имя/Email/Телефон/Промокод/согласие. **Без доставки и онлайн-оплаты** (заявка). **Нигде нет WhatsApp**. В подвале — оговорка «не является публичной офертой».

## Админка `/admin` (вход по паролю)
- Логин: cookie, пароль `ADMIN_PASSWORD` в `.env`. `COOKIE_SECURE="true"` (сайт по https).
- **Сводка**, **Товары** (поиск, сортировка «По названию / Сначала новые», пагинация, тумблер наличия, CRUD: создать/редактировать/удалить, **загрузка фото с компа до 3 МБ**), **Заказы** (смена статуса), **Настройки** (Telegram — но он заблокирован, см. ниже).
- **Уведомления о заказах — в самой админке** (`OrderNotifier`): опрос `/api/admin/orders/latest` каждые 10с → звук + плашка + мигание вкладки + браузерное уведомление. Работают, пока панель открыта. Заказы всегда падают в БД и раздел «Заказы».
- Заказ с сайта: `POST /api/order` → сохраняет в БД (best-effort шлёт в Telegram, но он режется).

## ⚠️ Уведомления: Telegram и SMTP ЗАБЛОКИРОВАНЫ хостером
С сервера **не достучаться** ни до `api.telegram.org` (v4 и v6 = 000), ни до SMTP (gmail/yandex 465/587 = FAIL). Поэтому боевой канал уведомлений — **в админке** (выше). HTTPS (443) работает. Если понадобится Telegram/email — только через внешний релей (Vercel/CF Worker) или почтовый API по 443 (Brevo/Unisender). Пользователь пока выбрал «только админка».

## Грабли (важно помнить)
- **Цена товара ограничена 2 млрд** в `toPrice` (`src/app/admin/actions.ts`): SQLite `Int` = 32 бита, значение >INT32 (было 5 млрд) **роняло чтение из БД** (Prisma P2023) → падали каталог и поиск.
- **Загруженные фото** (`public/uploads/`, в .gitignore) `next start` **НЕ отдаёт** (файлы, добавленные после сборки). Их отдаёт **nginx напрямую** (`location /uploads/ { alias /opt/carshine/public/uploads/; }`, прописано и в `deploy.sh`). В `next/image` локальные фото идут с `unoptimized`.
- **SSH порт 22 нестабилен** (провайдер, заходит с ретрая); открыты также 2222/443. Пользователь **сам выполняет команды на сервере** — давать однострочники под копипаст (см. память `server-command-preference`).
- **Сборка на Windows** иногда падает нативным крашем воркера — перемежающийся, помогает повтор; на Linux-сервере сборка стабильна. `tsc --noEmit` — надёжная проверка типов.

## Нагрузка
- Каталог ~**12 запросов/сек** (SSR, один процесс Node, кэша нет). Для старта ок (десятки одновременных). Пользователь оптимизацию пока отклонил. Резерв: ISR-кэширование страниц (revalidate + revalidatePath из админки) + gzip в nginx + PM2-кластер (2-е ядро). Ветку кэша делал и откатил — при росте трафика вернуть.

## Осталось (не срочно)
- Сменить дефолтный `ADMIN_PASSWORD` в `/opt/carshine/.env` — **пользователь отказался**, пароль сгенерён при деплое (16 символов), лежит в `.env`.
- Вернуть репозиторий в **private** (сейчас public ради простого автодеплоя без ключей).
- Перенести фото с tildacdn на свой хостинг (база `data/images/` готова).
- Оптимизация под нагрузку — если пойдёт трафик.
- Артефакт-предложение владельцу: `scratchpad/predlozhenie.html` (историческое, для питча).
