# CarShine — интернет-магазин детейлинга. Снимок проекта

Замена старого сайта на Tilda на кастомный магазин. **ЗАПУЩЕН В ПРОДЕ: https://carshine26.ru** (SSL, свой домен). Это источник правды по проекту — обновлять здесь.

---

## Стек
- **Next.js 16** (App Router) + React 19 + TypeScript + **Tailwind v4**
- **Prisma 6 + SQLite** (файловая БД `prisma/dev.db`, идеально под 1 ГБ/2 ГБ VPS)
- Дизайн: тёмный премиум (графит + золото), шрифты **Unbounded** (дисплей) + **Manrope** (текст), кириллица
- Иконки категорий/преимуществ — **Google Material Symbols** (шрифт подключён в `layout.tsx`)
- Описания товаров — **Markdown** (`react-markdown` + `remark-gfm` + `remark-breaks`, компонент `Markdown.tsx`)

## Данные / каталог
- **1747 товаров** из Tilda-экспорта (`Товары CarShine26.xlsx`) → `src/data/catalog.json` → сидятся в SQLite (`prisma/seed.ts`, `npm run db:seed`).
- 38 категорий сгруппированы в **6 разделов меню** (`src/lib/groups.ts`).
- **Бренды — динамически из БД** (`distinctBrands()`): главная, «О нас», фильтры. Статического списка брендов нет. Дубли LERATON→Leraton, Vintexx→Vintex слиты (`scripts/merge-brands.mjs`, разово на проде).
- **Фото — на своём сервере** (с 2026-11-25): `public/uploads/catalog/<sha1>.webp` (WebP ≤1200 px, ~53 МБ на 1866 фото), раздаёт nginx (`location /uploads/`), в next/image — unoptimized. Перенос — `scripts/migrate-photos.mjs` (скачивает с tildacdn, конвертирует, переписывает ссылки в БД; бэкап старых ссылок `prisma/photo-migration-backup.json`, откат `--rollback`; повторный запуск безопасен). `src/data/catalog.json` всё ещё со ссылками tildacdn — после `db:seed` прогнать скрипт снова. Загруженные через админку — `public/uploads/`, несколько фото на товар (`photosJson`).

## Архитектура данных
- `src/lib/shop.ts` — **клиент-безопасный** слой: типы, группы, категории (`src/data/categories.json`), `formatPrice`, `plural`, **`computeDiscount`** (единый расчёт скидки для витрины/админки/сервера).
- `src/lib/queries.ts` — **server-only** запросы к БД (Prisma). `Product.price` — **итоговая цена (со скидкой)**, `oldPrice` — до скидки, `discount` — подпись бейджа, `onSale`.
- `src/lib/reports.ts` + `src/lib/xlsx.ts` — отчёты по продажам и самописный генератор .xlsx (без зависимостей).
- `src/lib/db.ts` — Prisma client (singleton). `src/lib/auth.ts` — вход в админку. `src/lib/settings.ts` — key/value настройки в БД.
- Корзина (`src/lib/cart.tsx`) хранит **снимок товара** в localStorage (цена — со скидкой на момент добавления).

## Страницы (витрина)
- `/` главная (герой, преимущества, **карусель «Распродажа»** если есть товары со скидкой, разделы, популярные, все бренды кликабельны → `/catalog?brand=`)
- `/catalog` все товары; `/catalog/[group]` раздел с фильтрами. **Состояние фильтров/сортировки/страницы — в URL** (кнопка «назад» его восстанавливает).
- `/sale` — **раздел «Распродажа»** (товары с галочкой «Распродажа» и активной скидкой), с фильтрами каталога. Ссылка в верхней полосе шапки и в мобильном меню.
- `/product/[slug]` карточка (галерея со стрелками ◄►, бейдж скидки, старая цена/выгода, Markdown-описание, похожие, JSON-LD с итоговой ценой)
- `/search?q=` глобальный поиск. **Поиск везде (сайт, раздел каталога, админка) — через `normalizeSearch`/`matchesSearch` в `shop.ts`**: регистр, ё/е, неразрывные/невидимые пробелы, латинские буквы-двойники (A/А, C/С, O/О…), знаки препинания; совпадение — все слова в любом порядке или текст без пробелов. Причина: названия, скопированные с других сайтов, содержали NBSP и латиницу, и находились только при точном совпадении. SQLite `LIKE` в админке не используется (не знает регистра кириллицы); `/about`, `/contacts`, `/privacy`
- Корзина-заявка (Имя/Email/Телефон/Промокод/согласие), **без доставки и онлайн-оплаты**.
- Превью ссылки в мессенджерах: `src/app/opengraph-image.png` / `twitter-image.png` (1200×630).

## Акции / скидки (2026-10-12)
- В БД у `Product`: `discountType` (`""`/`percent`/`amount`), `discountValue`, `onSale`.
- Админка → товар → блок **«Цена и скидка»** (`PricingFields.tsx`): скидка в % (1–99) или суммой (меньше цены), предпросмотр итоговой цены; **галочка «Распродажа» неактивна без валидной скидки**. Сервер (`readDiscount` в `actions.ts`) повторно валидирует: невалидная скидка сбрасывается вместе с распродажей.
- Витрина: бейдж «−15%» / «−500 ₽» в углу фото (`DiscountBadge.tsx`), красная итоговая цена + зачёркнутая старая. Скидка учитывается в сортировке/фильтре по цене, корзине, JSON-LD, подсказках цен в редакторе заказа.
- Скидка без галочки «Распродажа» — бейдж и цена есть, но в `/sale` и карусель товар не попадает.

## Админка `/admin` (вход по паролю)
- Логин: cookie, пароль `ADMIN_PASSWORD` в `.env`. `COOKIE_SECURE="true"` (сайт по https).
- **Сводка**; **Товары** (поиск, фильтр по категории, сортировка «По названию / Сначала новые», пагинация — всё сохраняется при заходе в товар и возврате; тумблер наличия; CRUD; несколько фото до 5 МБ; автоподсказки бренда; скидки/распродажа; **цена редактируется прямо в списке** — `AdminPriceCell.tsx` + `updateProductPrice`: клик → поле, Enter/клик мимо — сохранить, Esc — отмена; если новая цена ломает скидку, скидка и распродажа сбрасываются); **Заказы** (статус, редактирование состава с пересчётом итога, удаление); **Отчёты** (период, статусы, KPI, график, топ товаров, экспорт .xlsx). Раздела «Настройки» (Telegram) больше нет.
- **Уведомления о заказах — в самой админке** (`OrderNotifier`). Заказ с сайта: `POST /api/order` → БД.

## Уведомления и персональные данные
Заказы сохраняются **только в нашей БД** (сервер в РФ) и видны в админке (OrderNotifier). **Отправка в Telegram удалена** (2026-11-25): была трансграничной передачей ПДн, к тому же хостер её блокировал. Иконки Material Symbols раздаются с нашего сервера (`public/fonts/material-symbols-outlined.woff2`, класс в `globals.css`), без запросов к Google. Шрифты Manrope/Unbounded — через next/font (тоже самохостинг). Внешних запросов со страниц нет (фото тоже свои).

**152-ФЗ — не выполнено:** уведомление в РКН не подано; политика на /privacy — заглушка; согласие на обработку не оформлено отдельно (требование с 01.09.2025); нет реквизитов продавца. Ждём от владельца: статус и реквизиты (ИП/ООО, ИНН, ОГРН, адрес), ответственного за ПДн, срок хранения заказов.

## Сервер / деплой
- **SpaceWeb VPS** `168.222.203.84`, Ubuntu 26.04, 2 CPU / 2 ГБ RAM / 20 ГБ (занято ~39%), **своп 2 ГБ**.
- Код в `/opt/carshine`, сервис **systemd `carshine`** (`next start` на :3000) за **nginx** (:80 → :443). SSL **Let's Encrypt**. **`client_max_body_size 6M`** (`/etc/nginx/conf.d/upload_size.conf`) — иначе загрузка фото >1 МБ падает с 413.
- **Автодеплой**: cron каждые 2 мин `autodeploy.sh` → **`git reset --hard origin/main`** + npm install + `prisma db push` (новые поля БД применяются сами) + build + restart. Лог `/var/log/carshine-deploy.log`. Пуш в `main` → прод за ~2 мин.
- **Авто-обновления ОС**: `unattended-upgrades` (security), авто-ребут при необходимости в 04:30 МСК.
- **GitHub** (публичный): `github.com/Opexzzzzzzzzzzzzz/carshine26`.

## Грабли (важно помнить)
- **Цена товара ограничена 2 млрд** в `toPrice` (SQLite `Int` 32 бита).
- **Загруженные фото** (`public/uploads/`) отдаёт **nginx напрямую**, в `next/image` — `unoptimized`.
- **Логотип** `public/logo.png` — `unoptimized` (оптимизатор кэшировал старую непрозрачную версию).
- **Server actions без redirect** за nginx не обновляли данные на клиенте — у действий, меняющих список, ставить `redirect`.
- **Даты в отчётах** бакетируются по локальному времени сервера (МСК), не по UTC.
- **Автодеплой** раньше вставал на `package-lock.json`, изменённом `npm install` на сервере — лечится `git reset --hard` (уже в скрипте).
- **SSH порт 22 нестабилен**; открыты 2222/443. Пользователь **сам выполняет команды на сервере** — давать однострочники.
- **Сборка на Windows** иногда падает воркером — повтор; `tsc --noEmit` надёжнее.
