# CarShine — новый сайт. План проекта

Замена текущего сайта на Tilda (`carshine26.com`) на кастомный интернет-магазин.
Цель — продать владельцу нормальный продающий сайт вместо витрины-заявки.

## Решения (зафиксировано)

- **Платформа:** кастом на **Next.js 16 (App Router) + React 19 + TypeScript + Tailwind v4**.
  Причина: скорость, SEO, полный контроль, отсутствие потолка конструктора.
- **Первый шаг:** кликабельный прототип для питча владельцу — **готов**.
- **Главные аргументы для владельца:** SEO/трафик, простая админка, премиум-вид/бренд.
- **Дизайн-система:** тёмный премиум (графит + золото), шрифты Unbounded (дисплей) + Manrope (текст),
  кириллица. Предложение владельцу оформлено в том же стиле — продукт и питч как один бренд.

## Проблемы старого сайта (диагноз, обоснование редизайна)

1. Каталог на главной пуст — «Ничего не найдено».
2. Нет корзины и онлайн-оплаты — «Заказать» = форма-заявка в WhatsApp.
3. Битые/пустые пункты меню (часть ведёт на `/`, часть не кликается).
4. Каша в URL (транслит: `sshetki-i-kisti` и т.п.), слабое SEO, магазин из разрозненных страниц.

## Этапы

### Этап 1 — Прототип ✅ ГОТОВО
- Дизайн-система и фирменный стиль.
- Главная: герой, категории, живые «Хиты продаж», блок керамики, новинки, бренды.
- Каталог: единая сетка, фильтры (бренд, цена-ползунок, наличие), поиск, сортировка.
- Карточка товара: галерея, характеристики, рейтинг, в корзину, похожие, JSON-LD.
- Корзина (drawer, localStorage), оформление заказа (доставка/оплата).
- Мокап админки (`/admin`): сводка, товары с переключателем наличия, заказы.
- SEO-заготовки: метатеги, `sitemap.xml`, Open Graph, чистые URL.
- Данные — демо-JSON (`src/lib/catalog.ts`), фото — брендовые заглушки.
- Предложение владельцу: `predlozhenie.html` (опубликовано как артефакт).
- Контакт для питча: **+7 905 493-99-85** (кнопка «Обсудить проект» + контакты).

### Этап 2 — Рабочий магазин (MVP), ~3–4 недели
- База товаров + реальная админка (добавление/цены/наличие).
- **ИИ-генерация описаний товаров** прямо в панели: по названию и характеристикам
  ИИ пишет продающее описание. Реализация — внешний API (кандидат: **GLM**), кнопка
  «Сгенерировать» в форме товара. Аргумент владельцу — часы вместо дней на заполнение каталога.
- Онлайн-оплата: карта + СБП (ЮKassa или аналог).
- Перенос ассортимента, реальные фото и описания.
- Оформление заказов с уведомлением менеджеру.

### Этап 3 — Запуск и рост, ~2–3 недели
- Перенос домена, 301-редиректы со старых URL (сохранить позиции в поиске).
- Яндекс.Метрика + цели.
- SEO-оптимизация категорий и карточек.
- Обучение владельца работе с панелью.

## База товаров (готово, из Tilda-экспорта)
Источник: `Товары CarShine26.xlsx` (экспорт из Tilda), колонка I — фото.
- **1747 товаров**, 38 категорий, 62 бренда. Цены 50–39000 ₽.
- Описания заполнены только у 8 из 1747 → кандидаты под ИИ-генерацию (этап 2).
- Файлы: `data/catalog.json` (нормализованная база + localImages), `data/products-raw.json`,
  `data/products.csv`, `data/image-map.csv`, `data/images-manifest.json`.
- **Картинки скачаны:** 1921 файл (png 1361 / jpg 486 / webp 74), 418 МБ, 0 ошибок.
  Лежат в `data/images/` (в .gitignore, в репозиторий не коммитим).
  Имена `{TildaUID}_{n}.{ext}` — мапятся на товар через manifest/catalog.
- 118 товаров с несколькими фото (до 6). Для заливки на хостинг всё готово: путь + оригинальный URL в manifest.

## Полная разработка v1 (в работе — переговоры прошли успешно)
Домен: **carshine26.ru** (переехали с .com). Заказы — Telegram-бот. Оплаты нет (заявка, как на текущем сайте). Переносим магазин + «О нас/Контакты», блог не переносим.

Сделано:
- Слой данных `src/lib/shop.ts` на реальном каталоге (`src/data/catalog.json`), 38 категорий сгруппированы в 6 разделов меню.
- Данные почищены: HTML-сущности и теги из названий/описаний убраны (чистый текст, абзацы).
- Фото: реальные с tildacdn через next/image (`next.config.ts` remotePatterns). Скачанную базу подключим при своём хостинге.
- Страницы: главная, каталог (все товары, пагинация «показать ещё»), раздел `/catalog/[group]` с фильтром по категориям/брендам/цене, карточка `/product/[slug]` (галерея, описание, похожие, JSON-LD), поиск `/search`, `/about`, `/contacts`, `/privacy`.
- Корзина 1:1 с оригиналом: поля Имя, Email, Телефон, Промокод, согласие. Без доставки/оплаты.
- Избранное (wishlist) — как на живом сайте.
- Заказ: `POST /api/order` → Telegram (env `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`); без env — лог в dev.
- Сборка проходит, страницы товара — SSR, остальное статикой.

## Что осознанно демо в прототипе (заменяется на этапе 2)
- Товары и метрики в `/admin` — демо-данные.
- Фото товаров — брендовые заглушки (`ProductImage.tsx`).
- Заказ на `/checkout` реально не отправляется, оплаты нет.
